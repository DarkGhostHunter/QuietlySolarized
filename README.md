## Features

- Normal "Solarized" variations
- APCA Compliant
- 18/18 checks pass, CIELAB sums all land at L*=110 (¹)
- "Contrasty" variations with lighter/darker background (not strictly-Solarized compliant).
- If does not f*ckign worn my eyes out.

> [!TIP]
>
> **1**: Think of it as a mathematically "perfect" theme. It balances colors so they share the same perceived brightness, ensuring maximum readability and zero eye strain, whether in light or dark mode.
